# Кадры Процедурного генератора баннеров

Снято для веб-версии Blazor WebAssembly + SkiaSharp (.NET 10, PWA).
Основной размер – 1440 × 1164..1395 (увеличенная высота до 1440 × 2639 для открытых секций калибровки без подрезки
рамок); мобильный экран – 390 × 876.
